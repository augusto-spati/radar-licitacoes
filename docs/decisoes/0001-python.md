# 0001. Python como linguagem

## Contexto
O projeto é de estudo, com foco em sistemas de dados e, mais tarde, em IA. A linguagem precisa aparecer nas vagas que o Augusto quer, ser uma que ele já usou e servir bem à parte de IA.

## Opções
- **Python.**
- **Go.**
- **.NET**, que ele já domina.

## Escolha
Python (3.13, gerenciado com uv).

## Trade-off
Python aparece nas vagas, ele já usou e é a linguagem mais forte para a parte de IA. .NET não fecharia nenhuma lacuna. Go somaria uma linguagem nova aos conceitos de dados que já são o objeto de estudo. O custo é abrir mão de tipagem estática nativa e de desempenho; mypy em modo estrito cobre a primeira parte, e o gargalo aqui é a API lenta do PNCP, não a CPU.
